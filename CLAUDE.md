# Notes for AI coding agents

Read [CONTRIBUTING.md](CONTRIBUTING.md) before writing code, commit messages or pull request text.
The rule that matters most: **this repository is public, so nothing personal or specific to anyone's
home setup goes in it.** That covers real names, IP addresses, machine and device names, local paths,
which password manager or backup someone uses, secrets, and real app data. This applies to files,
commits and everything written on GitHub (pull requests, comments, issues, release notes). Use
made-up names (Robin, Kai) and example addresses (`192.168.1.20`).

If a task needs details of a particular setup, ask for them in the conversation and keep them out of
the repository.

Before adding a dependency or building a connector, check [docs/third-party-reference.md](docs/third-party-reference.md)
for the official docs and license of each library, service and standard the plans name.
